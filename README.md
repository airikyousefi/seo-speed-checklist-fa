## 1. سئو فنی (Technical SEO)

پایهٔ همه‌چیز — اگه این‌ها نباشه، بقیهٔ تلاش‌ها هدر می‌ره:

- [ ] سایت با **HTTPS** کامل لود می‌شه (بدون اخطار قفل سبز، ریدایرکت http → https)
- [ ] نسخهٔ **www و بدون www** به یک آدرس واحد ریدایرکت می‌شه (Canonical)
- [ ] فایل **sitemap.xml** وجود داره و توی **Google Search Console** ثبت شده
- [ ] فایل **robots.txt** درست تنظیم شده (صفحات مهم بلاک نیستن)
- [ ] هر صفحه تگ **canonical** اختصاصی داره
- [ ] ساختار **H1 → H2 → H3** درسته (فقط یک H1 در هر صفحه)
- [ ] خطاهای **404 و ریدایرکت‌های زنجیره‌ای** پاک‌سازی شدن
- [ ] **Breadcrumb** (مسیر راهنما) فعال و دارای Schema است
- [ ] داده‌ساختاریافته (**Schema.org**) برای مقالات، محصولات و کسب‌وکار اضافه شده
- [ ] سایت **Mobile-First** است — در گوگل، نسخهٔ موبایل ملاک ایندکس است
- [ ] آدرس‌ها (URL) کوتاه، خوانا و فارسی/انگلیسی یکدست هستند

## 2. سرعت و Core Web Vitals

سرعت = رتبه = مشتری. اعداد هدف (موبایل):

| معیار | هدف | یعنی چی؟ |
|---|---|---|
| **LCP** | زیر ۲.۵ ثانیه | بزرگ‌ترین عنصر صفحه چقدر سریع میاد |
| **INP** | زیر ۲۰۰ میلی‌ثانیه | واکنش صفحه به کلیک/لمس |
| **CLS** | زیر ۰.۱ | نپریدن المان‌ها هنگام لود |

- [ ] تصاویر **WebP/AVIF** شدن و **lazy-load** دارن
- [ ] عرض تصاویر با `width` و `height` مشخص شده (جلوگیری از CLS)
- [ ] **کش مرورگر و سرور** فعال است
- [ ] CSS و JS **فشرده و Minify** شدن
- [ ] فونت‌های فارسی بهینه شدن (`font-display: swap` + فقط وزن‌های لازم)
- [ ] از **CDN** استفاده می‌شه (مثل Cloudflare — پلن رایگانه)
- [ ] اسکریپت‌های غیرضروری به انتهای صفحه منتقل یا حذف شدن
- [ ] نتیجهٔ **PageSpeed Insights موبایل بالای ۸۰** است

## 3. سئو محتوا

- [ ] برای هر صفحه **یک کلمهٔ کلیدی اصلی** تعریف شده
- [ ] تحقیق کلمه کلیدی **به فارسی** انجام شده (املاهای مختلف: «سایت» / «سایت»، فاصله‌گذاری، نیم‌فاصله)
- [ ] تگ **Title** زیر ۶۰ کاراکتر و شامل کلمهٔ کلیدی است
- [ ] **Meta Description** جذاب زیر ۱۶۰ کاراکتر نوشته شده
- [ ] محتوا **بهتر و کامل‌تر از رقبا** در صفحهٔ اول گوگل است
- [ ] **لینک‌سازی داخلی** بین صفحات مرتبط انجام شده
- [ ] صفحات تکراری/بی‌محتوا (Thin Content) حذف یا ادغام شدن
- [ ] **FAQ** به صفحات خدمات اضافه شده (شانس نمایش در گوگل بالاتر می‌ره)

## 4. سئو محلی برای کسب‌وکار ایرانی

- [ ] پروفایل **Google Business Profile** ساخته و تأیید شده
- [ ] **نام، آدرس و تلفن (NAP)** در همه‌جا یکسان است
- [ ] صفحهٔ تماس با **Schema LocalBusiness** علامت‌گذاری شده
- [ ] برای هر شهر/منطقهٔ هدف، صفحهٔ اختصاصی ساخته شده
- [ ] نظرات مشتریان دریافت و پاسخ داده می‌شه

## 5. نکات خاص وردپرس

- [ ] تم سبک و بهینه (نه دموی سنگین ThemeForest با ۴۰ افزونه)
- [ ] فقط **افزونه‌های ضروری** نصب باشه — هر افزونه = یک نقطهٔ کندی
- [ ] سئو: **Rank Math** یا **Yoast** (یکی، نه هر دو!)
- [ ] کش: **WP Rocket / LiteSpeed Cache / W3 Total Cache**
- [ ] بهینه‌سازی تصویر: **ShortPixel / Imagify / Smush**
- [ ] **به‌روزرسانی خودکار** هسته، تم و افزونه‌ها فعال است
- [ ] افزونه‌های غیرفعال و تم‌های اضافه **حذف** شدن (نه فقط غیرفعال)
- [ ] **نسخهٔ پشتیبان خودکار** (مثل UpdraftPlus) تنظیم شده

## 6. چک‌لیست قبل از لانچ

- [ ] فارسی و انگلیسی سایت هر دو تست شدن (فونت، راست‌چین، شکستگی حروف)
- [ ] فرم‌ها تست شدن و **ایمیل/پیام واقعاً دریافت می‌شه**
- [ ] شماره تلفن و واتساپ **کلیک‌خور** هستند (`tel:` و `wa.me`)
- [ ] تمام لینک‌های داخلی چک شدن (بدون 404)
- [ ] فاوآیکن و تصویر **OG** (پیش‌نمایش اشتراک‌گذاری) تنظیم شده
- [ ] **Google Analytics / Search Console** وصل شدن
- [ ] صفحات قانونی (حریم خصوصی، قوانین) موجودند
- [ ] تست نهایی سرعت روی **اینترنت موبایل ایران** انجام شده
